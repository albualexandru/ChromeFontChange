# ChromeFontChange

ChromeFontChange is a Google Chrome extension that lets you pick a preferred font for web pages.

## Features

- Choose a default font from the extension options page
- Change the font from the extension popup when you click the toolbar icon
- Change the font from the page right-click context menu
- Automatically apply the saved font to supported web pages

## Load the extension

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this repository folder
