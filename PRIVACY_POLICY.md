# Privacy Policy

_Last updated: 2026-07-10_

ChromeFontChange ("the extension") is a Google Chrome extension that lets you choose a preferred font for web pages.

## Data Collection

ChromeFontChange does not collect, transmit, sell, or share any personal information or browsing data. The extension does not use analytics, tracking, or advertising services, and it does not communicate with any external server.

## Data Storage

The extension uses Chrome's built-in `storage` permission to save your selected font preference locally (and, if Chrome sync is enabled, synced across your own signed-in devices via your Google account). This data:

- Stays under your control and is never sent to the developer or any third party.
- Is only used to remember and apply your chosen font when you browse web pages.
- Can be removed at any time by uninstalling the extension or clearing its stored data through Chrome's extension settings.

## Permissions

- **storage**: used to save your font preference.
- **contextMenus**: used to add a right-click menu option for changing the page font.
- **Content scripts** run on web pages solely to apply your chosen font locally in your browser; they do not read, collect, or transmit page content or personal data.

## Changes to This Policy

If this privacy policy is updated, the changes will be reflected in this file with an updated "Last updated" date.
